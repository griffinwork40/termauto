termauto

Local-first LLM shell completion for zsh on Apple Silicon.

Press Ctrl-Space at your prompt and get 3–5 ranked candidate commands from a model running on your Mac. Pick one with a number key. Nothing leaves the machine.

Why not ghost text

The cotabby pattern is ghost text + Tab. That works great for prose. It is a footgun in a shell: a hallucinated rm -rf or git push --force that you reflex-Tab-Enter before reading does real damage.

So termauto splits the two halves of an autocomplete apart and treats them differently.

Generation

Fast and speculative. The daemon returns 3–5 candidates the instant you ask.

Commitment

Deliberate. You read the list, then press a number to accept exactly one.

$BUFFER is never mutated until you pick.

Once you trust the model against your history and cwd corpus, a future --ghost mode can be added as an additive rendering path. The daemon, prompt schema, and ranker built here carry over unchanged.

How it works
┌─────────────────────────────────────────────────────────────┐
│                          your zsh                            │
│   ┌──────────────────────┐    ┌────────────────────────────┐ │
│   │ termauto.zsh widget  │    │ termauto_ghost.zsh strategy│ │
│   │   Ctrl-Space → panel │    │   typing → autosuggest hook│ │
│   │   ↓ POSIX exec       │    │   ↓ curl                   │ │
│   │   termauto suggest…  │    │   POST /suggest_inline     │ │
│   └──────────────────────┘    └────────────────────────────┘ │
└─────────────────┤──────────────────────────┤─────────────────────┘
              │ HTTP localhost:8765      │
              ▼                          ▼
┌─────────────────────────────────────────────────────────────┐
│                      termauto daemon                         │
│  FastAPI /complete         → build_messages       (panel)    │
│          /suggest_inline   → build_inline_messages (ghost)   │
│                              ↓                               │
│                            inference.py                      │
│                              ├─ generate()       (blocking)  │
│                              ├─ generate_stream() (streaming)│
│                              └─ mlx-lm (warm)                │
└─────────────────────────────────────────────────────────────┘

The widget and the ghost strategy talk to one local daemon over localhost:8765. The model is held warm in memory — no cold-start penalty per request.

Local-first

Nothing leaves your Mac.

Inference runs on-device via MLX on Apple Silicon. The daemon binds to 127.0.0.1:8765 and never dials out. Your shell history, working directory, and commands are never transmitted anywhere.
