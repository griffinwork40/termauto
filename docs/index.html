termauto

Local-first LLM shell completion for zsh on Apple Silicon.
Press Ctrl-Space at your prompt. Pick from 3–5 ranked candidates. Nothing leaves your Mac.

Why not ghost text

The cotabby pattern is ghost text + Tab. That works great for prose. It is a footgun in a shell: a hallucinated rm -rf or git push --force that you reflex-Tab-Enter before reading does real damage.

termauto separates generation from commitment:

  • Generation is fast and speculative. The daemon returns 3–5 candidates.
  • Commitment is deliberate. You read, then press a number to accept.
  • $BUFFER is never mutated until you pick.

Once you trust the model against your history and cwd corpus, a future --ghost mode can be added as an additive rendering path. The daemon, prompt schema, and ranker built here carry over unchanged.

How it works

┌─────────────────────────────────────────────────────────────┐
│                          your zsh                            │
│   ┌──────────────────────┐    ┌────────────────────────────┐ │
│   │ termauto.zsh widget  │    │ termauto_ghost.zsh strategy│ │
│   │   Ctrl-Space → panel │    │   typing → autosuggest hook│ │
│   │   ↓ POSIX exec       │    │   ↓ curl                   │ │
│   │   termauto suggest…  │    │   POST /suggest_inline     │ │
│   └──────────────────────┘    └────────────────────────────┘ │
└─────────────────┤──────────────────────────┤─────────────────────┘
              │ HTTP localhost:8765      │
              ▼                          ▼
┌─────────────────────────────────────────────────────────────┐
│                      termauto daemon                         │
│  FastAPI /complete         → build_messages       (panel)    │
│          /suggest_inline   → build_inline_messages (ghost)   │
│                              ↓                               │
│                            inference.py                      │
│                              ├─ generate()       (blocking)  │
│                              ├─ generate_stream() (streaming)│
│                              └─ mlx-lm (warm)                │
└─────────────────────────────────────────────────────────────┘

The zsh widget and ghost strategy talk to the same local daemon over localhost:8765. The daemon holds the model warm in memory so there is no cold-start penalty per request.

Local-first

Nothing leaves your Mac. Inference runs on-device via MLX on Apple Silicon. The daemon binds to 127.0.0.1:8765 and never dials out. Your shell history, working directory, and commands are never transmitted anywhere.

Latency on M-series

Model Size Latency Notes
Qwen3-1.7B-4bit (default) ~1GB ~600ms Newer generation, good diversity
Qwen2.5-Coder-1.5B-Instruct-4bit ~900MB ~580ms Code-tuned, reliable 3–5 candidates
Qwen3-0.6B-4bit ~400MB ~300ms Faster but quality drops noticeably

Install

git clone https://github.com/griffinwork40/termauto termauto
cd termauto
./install.sh
termauto start

macOS Apple Silicon  ·  zsh 5.1+  ·  Python 3.10+  ·  ~1GB disk
